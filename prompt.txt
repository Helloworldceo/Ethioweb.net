Build a modern, fast, and professional website for my domain: ethioweb.net.

Project overview:
Ethioweb is a digital platform that helps individuals and businesses build and manage their online presence in one place. It should include both a public-facing website and a user profile system where people can create profiles, upload CVs, portfolios, certificates, links, and other professional information, while choosing what is public or private.

Main goals:
1. Showcase my personal work, projects, and business services
2. Allow users to create and manage their own profiles
3. Let users upload CVs, portfolios, certificates, and links and other can view and download there cv and business card
4. Give users privacy controls for public and private information
5. Provide a clean public profile page for each user
6. Make the platform scalable for future growth
7. users can search a name or a username to find each other
